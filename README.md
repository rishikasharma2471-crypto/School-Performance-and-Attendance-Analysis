# School Performance & Academic Analytics Tool

A Core Python-based data processing tool that reads a real-world dataset from Kaggle and provides interactive student performance analysis through a command-line interface.

## How it works

### 1. Ingests Raw Data
Securely opens and parses a raw `student_data.csv` file containing 395+ student records from Kaggle.

### 2. Structures Database
Converts comma-separated lines into organized nested Python data structures using Lists and Dictionaries.

### 3. Filters Academic Risk
Scans the database using loop control mechanisms to automatically identify profiles with past academic failures.

### 4. Computes Key Metrics
Analyzes final scores (`G3` metrics out of 20) to instantly calculate and output the absolute classroom pass/fail ratio.

## Tech Stack

* **Python**
* **CSV Module**
